# 02 创建站点

> 目标：本地跑起一个空博客，浏览器能打开 `http://localhost:1313`。

---

## 一、创建站点

选一个放项目的目录（路径**不要带中文和空格**，能少踩很多坑）：

```bash
# macOS / Linux
cd ~/Documents
hugo new site myblog
cd myblog

# Windows PowerShell
cd $env:USERPROFILE\Documents
hugo new site myblog
cd myblog
```

输出类似：

```
Congratulations! Your new Hugo site was created in .../myblog.

Just a few more steps...
```

---

## 二、认识目录结构

```
myblog/
├── archetypes/      # 新建文章时的模板（front matter 格式）
├── assets/          # 需要 Hugo 处理的资源（SCSS、图片处理源文件）
├── content/         # ★ 你的文章都放这里
├── data/            # 结构化数据（JSON/YAML，供模板读取）
├── i18n/            # 多语言文本
├── layouts/         # 模板（覆盖主题用）
├── static/          # 原样复制到网站根目录（图片、favicon、robots.txt）
├── themes/          # 主题
├── hugo.toml        # ★ 配置文件
└── public/          # 构建产物（自动生成，不要提交到 git）
```

**两个关键点**：

- `content/` 放内容，`static/` 放静态资源（图片通常放 `static/images/`）
- `public/` 是编译结果，**加入 .gitignore**

---

## 三、初始化 Git

```bash
git init
```

立刻创建 `.gitignore`：

```gitignore
public/
resources/
.hugo_build.lock
.DS_Store
```

> `resources/` 是 Hugo 的图片处理缓存，也不需要提交。

---

## 四、跑起来看看

```bash
hugo server
```

输出：

```
Start building sites …
Built in 45 ms
Web Server is available at http://localhost:1313/ (bind address 127.0.0.1)
```

浏览器打开 <http://localhost:1313>，你会看到一个**什么都没有的白页**——正常，因为还没装主题、没写文章。

### 开发时常用的参数

| 命令 | 作用 |
| --- | --- |
| `hugo server` | 启动本地服务器，改文件自动刷新 |
| `hugo server -D` | **包含草稿**（draft: true 的文章） |
| `hugo server --port 8080` | 换端口（1313 被占用时） |
| `hugo server --bind 0.0.0.0` | 允许局域网访问（手机上预览） |
| `hugo` | 手动构建到 `public/` |
| `hugo --minify` | 压缩 HTML/CSS/JS |

**`-D` 很重要**：新文章默认是草稿，不加 `-D` 就看不到。

## 五、验证

```
□ hugo server 能启动，没有红色报错
□ 浏览器打开 localhost:1313 能看到页面（白页也算成功）
□ 修改文件后浏览器自动刷新
□ 按 Ctrl+C 能停止服务器
```

---

## 常见错误

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `Error: module "xxx" not found` | 主题没装 | 先看 [03 章](03-配置与主题.md) |
| `port 1313 already in use` | 上次的服务器没关 | `--port 8080`，或杀进程 |
| `failed to load config: ... toml` | 配置文件语法错 | 检查引号、括号是否成对 |
| 页面 404 | 内容没写到 `content/` 下 | 确认文件位置 |
| 中文路径报错 | Hugo 对非 ASCII 路径支持不好 | 项目放在纯英文路径 |
