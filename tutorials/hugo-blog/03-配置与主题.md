# 03 配置与主题

> 目标：装上 PaperMod 主题，把网站改成像样的博客：标题、简介、菜单、社交图标。

---

## 一、安装主题

### 方式 A：Git Submodule（推荐）

好处：主题更新时 `git submodule update --remote` 一键升级。

```bash
git submodule add https://github.com/adityatelange/hugo-PaperMod themes/PaperMod
```

### 方式 B：直接下载（更简单，但不会自动更新）

```bash
# 下载 zip 后解压到 themes/PaperMod
git clone https://github.com/adityatelange/hugo-PaperMod themes/PaperMod
```

> 如果你不熟悉 submodule，用方式 B，把 `themes/PaperMod` 整个提交进仓库也能用。
> 国内访问 GitHub 慢的话，可以用 `https://codeload.github.com/adityatelange/hugo-PaperMod/zip/refs/heads/master` 下载 zip。

## 二、最小可用配置

打开 `hugo.toml`，替换成：

```toml
baseURL = 'https://example.com/'
locale = 'zh-cn'
defaultContentLanguage = 'zh'
title = '我的博客'
theme = 'PaperMod'

[params]
  env = 'production'
  description = '记录一些东西'
  author = '你的名字'
  defaultTheme = 'auto'          # auto / light / dark
  ShowReadingTime = true
  ShowShareButtons = false
  ShowPostNavLinks = true
  ShowBreadCrumbs = true
  ShowCodeCopyButtons = true
  ShowWordCount = true
  UseHugoToc = true

[params.homeInfoParams]
  Title = '你好，我是 XXX'
  Content = '''
这里写一段自我介绍。
支持 **Markdown** 语法，也可以换行。
'''

[[params.socialIcons]]
  name = 'github'
  url = 'https://github.com/你的用户名'

[[params.socialIcons]]
  name = 'mail'
  url = 'mailto:你的邮箱@example.com'

[menu]
  [[menu.main]]
    identifier = 'posts'
    name = '文章'
    url = '/posts/'
    weight = 10
  [[menu.main]]
    identifier = 'archives'
    name = '归档'
    url = '/archives/'
    weight = 20
  [[menu.main]]
    identifier = 'search'
    name = '搜索'
    url = '/search/'
    weight = 30
  [[menu.main]]
    identifier = 'tags'
    name = '标签'
    url = '/tags/'
    weight = 40
```

保存后刷新浏览器，应该能看到首页有标题和简介了。

## 三、启用归档页和搜索页

菜单里的 `/archives/` 和 `/search/` 需要**先创建对应页面**，否则 404。

### 归档页

新建 `content/archives.md`：

```markdown
---
title: "归档"
layout: "archives"
url: "/archives/"
summary: "按时间排序的全部文章"
hidemeta: true
---
```

### 搜索页

新建 `content/search.md`：

```markdown
---
title: "搜索"
layout: "search"
url: "/search/"
summary: "搜索文章"
placeholder: "输入关键词…"
hidemeta: true
---
```

同时在 `hugo.toml` 里加：

```toml
[outputs]
  home = ["HTML", "RSS", "JSON"]
```

> `JSON` 输出是搜索功能的数据源，不加会报「搜索索引不存在」。

## 四、PaperMod 常用参数速查

| 参数 | 作用 | 推荐值 |
| --- | --- | --- |
| `defaultTheme` | 默认配色 | `auto`（跟随系统） |
| `ShowReadingTime` | 显示阅读时长 | `true` |
| `ShowCodeCopyButtons` | 代码块复制按钮 | `true` |
| `ShowShareButtons` | 分享按钮 | `false` |
| `ShowBreadCrumbs` | 面包屑 | `true` |
| `ShowPostNavLinks` | 上一篇/下一篇 | `true` |
| `ShowToc` | 文章目录 | `true` |
| `TocOpen` | 目录默认展开 | `false` |
| `disableThemeToggle` | 隐藏深浅色按钮 | `false` |
| `assets.favicon` | 网站图标 | 见下 |

### 加 favicon

1. 准备一个 `favicon.ico`，放到 `static/`
2. 配置：

```toml
[params.assets]
  favicon = "/favicon.ico"
```

### 加头像（PaperMod 内置）

把头像放到 `assets/avatar.png`，然后：

```toml
[params.label]
  icon = "avatar.png"
  iconHeight = 36
```

效果：标题左边出现头像，圆形裁切需要自己加 CSS（见 [05 章](05-自定义样式.md)）。

## 五、验证

```
□ 首页有标题和简介
□ 顶部菜单有「文章 / 归档 / 搜索 / 标签」
□ 点归档、搜索不 404
□ 有 GitHub、邮箱图标，点击能跳转
□ 右上角深浅色切换按钮能用
```

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 页面全白/没样式 | 主题路径不对 | 确认 `themes/PaperMod` 里有 `layouts/` |
| `module "PaperMod" not found` | 主题没装好 | 重新 clone 或检查目录名大小写 |
| 菜单点了 404 | 页面没创建 | 见第三节 |
| 搜索框不能用 | 没有 JSON 输出 | 加 `[outputs]` 配置 |
| 中文显示成方块 | 主题字体不含中文 | 见 05 章加中文字体 |
| 配置改了没生效 | 服务器缓存 | `Ctrl+C` 重启 `hugo server` |
