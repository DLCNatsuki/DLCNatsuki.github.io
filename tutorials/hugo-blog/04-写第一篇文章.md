# 04 写第一篇文章

> 目标：会用 `hugo new` 建文章，懂 front matter 每个字段，能插图片和代码块。

---

## 一、新建文章

```bash
hugo new content posts/hello.md
```

> 老版本 Hugo 是 `hugo new posts/hello.md`，新版本推荐加 `content`。

生成的文件：

```markdown
+++
date = '2026-11-20T10:00:00+08:00'
draft = true
title = 'Hello'
+++
```

**`draft = true` 表示草稿**，`hugo server` 看不到，必须 `hugo server -D`。

---

## 二、Front matter 字段

Hugo 支持 TOML（`+++`）、YAML（`---`）、JSON 三种，选一种用到底别混。

### 常用字段

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| `title` | 标题 | `'我的第一篇文章'` |
| `date` | 发布时间 | `2026-11-20T10:00:00+08:00` |
| `draft` | 是否草稿 | `false` |
| `tags` | 标签（可多个） | `['Hugo', '教程']` |
| `categories` | 分类 | `['技术']` |
| `summary` | 摘要（列表页显示） | `'本文介绍…'` |
| `weight` | 排序权重 | `10` |
| `ShowToc` | 本文是否显示目录 | `true` |
| `cover.image` | 封面图 | `'images/cover.jpg'` |
| `cover.alt` | 封面替代文字 | `'封面'` |
| `slug` | 自定义 URL | `'hello-hugo'` |

### 完整示例

```toml
+++
title = '用 Hugo 搭一个博客'
date = 2026-11-20T10:00:00+08:00
draft = false
tags = ['Hugo', '教程', '静态网站']
categories = ['技术']
summary = '从零开始，三步搭起一个能自动部署的博客。'
ShowToc = true
ShowReadingTime = true

[cover]
  image = 'images/hugo-cover.jpg'
  alt = 'Hugo 博客封面'
+++
```

## 三、Markdown 语法速查

### 标题

```markdown
# 一级标题（文章内一般不用，标题已经在 front matter 里）
## 二级标题
### 三级标题
```

> `##` 及以下会自动进目录（如果开了 `ShowToc`）。

### 强调

```markdown
**加粗**  *斜体*  ~~删除线~~  `行内代码`
```

### 列表

```markdown
- 无序
- 列表

1. 有序
2. 列表
```

### 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/images/photo.jpg)
```

### 引用

```markdown
> 这是引用。
```

### 表格

```markdown
| 列 1 | 列 2 |
| --- | --- |
| A | B |
```

### 代码块

````markdown
```python
def hello():
    print("Hello")
```
````

> 代码块的语言名要写对，才有高亮。

### 分割线

```markdown
---
```

## 四、图片怎么放

### 方式 A：放 `static/`（推荐新手）

1. 图片放到 `static/images/photo.jpg`
2. 文章里写 `![说明](/images/photo.jpg)`

**注意**：路径以 `/` 开头，指向网站根目录。

### 方式 B：Page Bundle（同目录管理，推荐进阶）

```
content/posts/my-article/
├── index.md
└── photo.jpg
```

文章里写 `![说明](photo.jpg)`（不带 `/`）。

好处：图片和文章绑定，迁移/删除时不会漏。

## 五、草稿与发布

| 状态 | 本地预览 | 线上 |
| --- | --- | --- |
| `draft = true` | 只有 `-D` 能看到 | 不发布 |
| `draft = false` | 能看到 | 发布 |
| `date` 是未来 | 默认看不到 | 不发布（除非 `--buildFuture`） |

**踩坑提醒**：`date` 写成未来时间，Hugo 不构建，页面会 404。改时间或加 `--buildFuture`。

## 六、验证

```
□ hugo new content posts/xxx.md 能生成文件
□ hugo server -D 能看到草稿
□ 改 draft 为 false 后，不带 -D 也能看到
□ 图片能正常显示
□ 代码块有高亮和复制按钮
□ 标签页能按标签筛出文章
```

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 文章不显示 | `draft = true` 或日期是未来 | 改 `draft` / 日期 |
| 图片裂了 | 路径不对 | `static/images/a.jpg` → `/images/a.jpg` |
| 标签不生效 | `tags` 写成了字符串 | 要用数组 `['a', 'b']` |
| 中文 URL 乱码 | 标题当成了路径 | 加 `slug = 'english-slug'` |
| 目录没出现 | `ShowToc` 没开 | 在 `hugo.toml` 或 front matter 里开 |
