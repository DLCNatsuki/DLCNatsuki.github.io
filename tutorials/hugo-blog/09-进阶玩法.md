## 一、评论系统（Giscus）

免费、无需后端、基于 GitHub Discussions。

### 步骤

1. 仓库 → Settings → Features → 勾选 **Discussions**
2. 安装 Giscus App：<https://github.com/apps/giscus> → 选择你的仓库
3. 打开 <https://giscus.app/zh-CN>，填入仓库名，得到 `data-repo-id` 和 `data-category-id`
4. 创建 `layouts/_partials/comments.html`：

```html
{{- if (.Param "comments") }}
<div class="comments" style="margin-top:2.5rem;">
  <script src="https://giscus.app/client.js"
          data-repo="用户名/仓库名"
          data-repo-id="R_kgDOxxxx"
          data-category="Announcements"
          data-category-id="DIC_kwDOxxxx"
          data-mapping="pathname"
          data-strict="0"
          data-reactions-enabled="1"
          data-emit-metadata="0"
          data-input-position="top"
          data-theme="preferred_color_scheme"
          data-lang="zh-CN"
          data-loading="lazy"
          crossorigin="anonymous"
          async>
  </script>
</div>
{{- end }}
```

5. `hugo.toml` 开启：

```toml
[params]
  comments = true
```

**缺点**：评论者需要 GitHub 账号。国内用户可以换 [Waline](https://waline.js.org/)（需部署后端）。

## 二、访问统计

| 方案 | 特点 |
| --- | --- |
| **Google Analytics** | 功能全，国内加载慢 |
| **Umami**（自建/云） | 轻量、隐私友好 |
| **不蒜子** | 极简，国内快，只显示访问量 |
| Cloudflare Web Analytics | 免费，需域名接 Cloudflare |

### 不蒜子（最简单）

在 `layouts/_partials/extend_footer.html` 加：

```html
<script async src="//busuanzi.ibruce.info/busuanzi/2.3/busuanzi.pure.mini.js"></script>
<span id="busuanzi_container_site_pv">
  本站总访问量 <span id="busuanzi_value_site_pv"></span> 次
</span>
```

## 三、图片处理

Hugo 自带图片处理（需要 extended 版）：

```markdown
{{< figure src="/images/photo.jpg" title="标题" >}}
```

或直接用 Markdown + Hugo 的 `image` shortcode 做响应式。

**建议**：

- 上传前压缩到 **300 KB 以内**
- 用 WebP 格式（体积小 30%）
- 工具：[Squoosh](https://squoosh.app/)、[TinyPNG](https://tinypng.com/)

## 四、自定义 404 页面

新建 `layouts/404.html`：

```html
{{ define "main" }}
<main class="main">
  <div class="post-content" style="text-align:center;padding:4rem 1rem;">
    <h1>404</h1>
    <p>这个页面不见了。</p>
    <p><a href="{{ "" | absLangURL }}">回到首页</a></p>
  </div>
</main>
{{ end }}
```

> GitHub Pages 会自动使用根目录的 `404.html`。

## 五、RSS 与 SEO

Hugo 默认生成 `/index.xml`（RSS）。

SEO 基础：

```toml
[params]
  description = '站点描述，会出现在搜索结果里'
  keywords = ['关键词1', '关键词2']

[params.assets]
  favicon = '/favicon.ico'
```

每篇文章加 `summary` 字段，会用于列表页和搜索引擎摘要。

## 六、Mermaid 图表

在 Markdown 里画流程图：

```markdown
```mermaid
graph LR
  A[写作] --> B[提交]
  B --> C[自动部署]
```
```

需要在 `extend_footer.html` 引入 mermaid：

```html
<script type="module">
  import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@10/dist/mermaid.esm.min.mjs';
  mermaid.initialize({ startOnLoad: true, theme: 'default' });
</script>
```

## 八、多语言

`hugo.toml`：

```toml
defaultContentLanguage = 'zh'

[languages]
  [languages.zh]
    languageName = '中文'
    weight = 1
    contentDir = 'content'
  [languages.en]
    languageName = 'English'
    weight = 2
    contentDir = 'content/en'
```

文章放在对应目录下，文件名相同即为翻译版本。

## 九、加速国内访问

GitHub Pages 在国内访问不稳定，可选方案：

| 方案 | 说明 |
| --- | --- |
| **Cloudflare** | 免费 CDN，套在自定义域名上 |
| Vercel / Netlify | 自动部署，国内速度较好 |
| 国内对象存储 + CDN | 需备案 |
| 保持现状 | 只是慢，能打开 |

**Cloudflare 步骤**：域名 NS 改到 Cloudflare → 加 A 记录 → 开橙云代理。

## 十、写作效率技巧

| 技巧 | 做法 |
| --- | --- |
| 文章模板 | 改 `archetypes/default.md`，新建文章自动带 front matter |
| 草稿箱 | `draft: true`，`hugo server -D` 预览 |
| 短链接 | front matter 加 `slug = 'short-name'` |
| 批量改 | VS Code 全局替换（`Ctrl+Shift+H`） |
| 图片粘贴 | VS Code 插件 Paste Image 自动存到 `static/images/` |

### archetypes/default.md 示例

```markdown
+++
title = '{{ replace .File.ContentBaseName "-" " " | title }}'
date = {{ .Date }}
draft = true
tags = []
categories = []
summary = ''
ShowToc = true
+++

在这里开始写正文。
```
