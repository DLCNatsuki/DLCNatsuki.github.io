# 05 自定义样式与模板

> 目标：会覆盖主题的 CSS 和模板，做出自己的视觉风格，同时不破坏主题升级能力。

---

## 一、改颜色的三种方式

| 方式 | 难度 | 适合 |
| --- | --- | --- |
| 改主题自带的 CSS 变量 | ★ | 微调配色 |
| 加 `assets/css/extended/*.css` | ★★ | **推荐**，最省事 |
| 覆盖整个主题文件 | ★★★ | 大改结构 |

---

## 二、方式一：加自定义 CSS（推荐）

PaperMod 会自动加载 `assets/css/extended/` 下的**所有** `.css` 文件。

### 步骤

1. 建目录 `assets/css/extended/`
2. 新建 `custom.css`
3. 写样式，保存即生效

示例 `custom.css`：

```css
/* 标题字号 */
.post-title {
  font-size: 2.2rem;
}

/* 正文行高，中文排版更舒服 */
.post-content {
  line-height: 1.8;
}

/* 代码块圆角 */
.post-content pre {
  border-radius: 8px;
}

/* 链接加下划线 */
.post-content a {
  text-decoration: underline;
  text-underline-offset: 3px;
}
```

> **不用在 hugo.toml 里注册**，Hugo 会自动合并这些文件。

## 三、方式二：改 CSS 变量（换主题色）

PaperMod 用 CSS 变量定义颜色。在 `custom.css` 里覆盖：

```css
:root {
  --theme: #fff;              /* 背景 */
  --entry: #f5f5f5;           /* 卡片背景 */
  --primary: #1a1a1a;         /* 主文字 */
  --secondary: #666;          /* 次要文字 */
  --content: #222;            /* 正文 */
  --border: #e5e5e5;          /* 边框 */
  --code-bg: #f3f3f3;         /* 行内代码背景 */
  --link-color: #0b6bcb;      /* 链接 */
}

/* 深色模式 */
.dark {
  --theme: #1d1e20;
  --entry: #2e2e33;
  --primary: #e0e0e0;
  --secondary: #9b9b9b;
  --content: #d0d0d0;
  --border: #3a3a3a;
  --code-bg: #2a2a2a;
  --link-color: #6cb6ff;
}
```

### 找变量名的办法

浏览器按 `F12` → 选中元素 → 看右侧 Computed 里的 CSS 变量，或搜索主题的 `:root` 定义。

## 四、中文字体优化

PaperMod 默认字体对中文不够友好。加中文字体栈：

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
               "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
               "Noto Sans SC", sans-serif;
}

/* 代码用等宽字体 */
code, pre, kbd {
  font-family: "JetBrains Mono", "Cascadia Code", Consolas,
               "Courier New", monospace;
}
```

## 五、方式三：覆盖模板

Hugo 的模板查找顺序是：**项目 `layouts/` → 主题 `layouts/`**。
所以只要在项目里放同名文件，就会覆盖主题的。

### 例：给标题左边加头像

新建 `layouts/_partials/header.html`（Hugo 0.146+ 用 `_partials`，老版本是 `partials`）：

```html
{{- $label_text := (site.Params.label.text | default site.Title) }}
<header class="header">
  <nav class="header-nav">
    <div class="logo">
      {{- with site.Params.label.icon }}
      <img src="{{ . | absURL }}" alt="头像" width="32" height="32"
           style="border-radius:50%;margin-right:8px;vertical-align:middle;">
      {{- end }}
      <a href="{{ "" | absLangURL }}" accesskey="h" title="{{ $label_text }}">
        {{- $label_text -}}
      </a>
    </div>
  </nav>
</header>
```

> **技巧**：先把主题的 `themes/PaperMod/layouts/_partials/header.html` 复制到项目里，再改，比从零写快。

### 常见可覆盖的模板

| 文件 | 作用 |
| --- | --- |
| `layouts/_partials/header.html` | 顶部导航 |
| `layouts/_partials/footer.html` | 页脚 |
| `layouts/_partials/extend_footer.html` | 页脚追加内容（加脚本用） |
| `layouts/_partials/extend_head.html` | `<head>` 追加（加统计代码） |
| `layouts/_default/single.html` | 文章页 |
| `layouts/_default/list.html` | 列表页 |
| `layouts/index.html` | 首页 |

## 六、加一个「小游戏」或自定义页面

1. 新建 `content/games.md`：

```markdown
---
title: "小游戏"
layout: "single"
---

<iframe src="/games/snake/" width="100%" height="620"
        frameborder="0" style="border-radius:12px;"></iframe>
```

2. 把游戏文件放 `static/games/snake/index.html`
3. 菜单里加一项指向 `/games/`

> 内嵌 HTML 需要配置 `unsafe`：
> ```toml
> [markup.goldmark.renderer]
>   unsafe = true
> ```

## 七、加一段自定义脚本

新建 `layouts/_partials/extend_footer.html`：

```html
<script>
  // 例：图片点击放大
  document.querySelectorAll('.post-content img').forEach(img => {
    img.style.cursor = 'zoom-in';
    img.addEventListener('click', () => window.open(img.src, '_blank'));
  });
</script>
```

## 八、验证

```
□ 改 custom.css 后刷新能看到变化
□ 深色模式下颜色也正常
□ 覆盖的模板生效，且没破坏其他部分
□ hugo server 没有模板报错
```

---

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| CSS 不生效 | 文件没放对位置 | 必须在 `assets/css/extended/` |
| 改了模板报错 | 变量名或语法错 | 先复制原模板再改 |
| 内嵌 HTML 不渲染 | Goldmark 默认禁用 | 开 `unsafe = true` |
| 主题升级后样式冲突 | 覆盖了整个文件 | 尽量只加 CSS，少改模板 |
