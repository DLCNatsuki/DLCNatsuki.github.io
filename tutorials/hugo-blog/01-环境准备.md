# 01 环境准备

> 目标：装好 Hugo 和 Git，能执行 `hugo version` 和 `git --version`。

---

## 需要装什么

| 工具 | 作用 | 是否必需 |
| --- | --- | --- |
| **Hugo Extended** | 把 Markdown 编译成网页 | ✅ 必需 |
| **Git** | 版本管理 + 推送到 GitHub | ✅ 必需 |
| 编辑器 | 写 Markdown | 推荐 VS Code |
| GitHub 账号 | 托管仓库 + 免费 Pages | ✅ 必需 |

> 为什么必须 **Extended** 版：普通版不支持 SCSS/SASS 编译，很多主题（包括 PaperMod 的部分功能）会报错。

---

## 一、安装 Hugo

### Windows

**方式 1：winget（最简单）**

```powershell
winget install Hugo.Hugo.Extended
```

**方式 2：手动下载**

1. 打开 <https://github.com/gohugoio/hugo/releases>
2. 找最新版的 `hugo_extended_x.yyy.z_windows-amd64.zip`
3. 解压，把 `hugo.exe` 放到一个固定目录，比如 `C:\Users\你的名字\tools\hugo\`
4. 把这个目录加入 PATH：
   - 搜索「环境变量」→ 编辑系统环境变量 → 环境变量
   - 在「用户变量」里选中 `Path` → 编辑 → 新建 → 粘贴目录
   - **确定后要重开终端才生效**

### macOS

```bash
brew install hugo
```

### Linux

```bash
# Debian/Ubuntu
sudo apt install hugo

# 或下二进制
wget https://github.com/gohugoio/hugo/releases/download/v0.169.0/hugo_extended_0.169.0_linux-amd64.deb
sudo dpkg -i hugo_extended_0.169.0_linux-amd64.deb
```

## 二、安装 Git

### Windows

```powershell
winget install Git.Git
```

或者下载 <https://git-scm.com/download/win>，一路默认安装。

> 如果你不想装完整版，也可以用 **MinGit**（约 50 MB，解压即用），适合只想 push 不想折腾的人。

### macOS / Linux

```bash
# macOS
brew install git
# 或 xcode-select --install

# Linux
sudo apt install git
```

## 三、验证安装

打开**新的**终端窗口，执行：

```bash
hugo version
git --version
```

**期望输出**（版本号可能不同）：

```
hugo v0.169.0-... extended windows/amd64 BuildDate=...
git version 2.56.0.windows.1
```

⚠️ **关键检查**：`hugo version` 的输出里必须有 **`extended`** 这个词。
没有就是装错了，重装 Extended 版。

## 四、配置 Git 身份

第一次用 Git 需要告诉它你是谁：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

> 邮箱建议用 GitHub 提供的 noreply 邮箱，避免暴露真实邮箱：
> `12345678+用户名@users.noreply.github.com`

验证：

```bash
git config --global --list
```

---

## 五、注册 GitHub 账号

1. 打开 <https://github.com/signup>
2. 填邮箱、密码、用户名
3. **用户名很关键**：如果你打算用 `用户名.github.io` 做网址，它会成为你的域名前缀
   - 只能用字母、数字、连字符
   - 建议全小写

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `hugo: 无法将"hugo"项识别为...` | 没加 PATH，或终端没重启 | 加 PATH 后**重开终端** |
| `hugo version` 没有 `extended` | 装了普通版 | 重装 Extended |
| `git: command not found` | Git 没装或没进 PATH | 重装 Git，勾选 "Add to PATH" |
| winget 报错 `0x80073D02` | 有程序占用 | 重启后重试 |
| 中文乱码 | 终端编码不是 UTF-8 | `chcp 65001`（Windows） |
